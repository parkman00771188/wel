# AdSense 점검 — 2026-09-22

## 판단

첨부 화면은 승인 거절이 아니라 **심사 중**이다. 사용자는 AdSense 홈에서
“사이트의 광고 게재 가능 여부 검토 중 / 모든 단계를 완료했습니다”라고 확인했다.
따라서 현재 정보로는 미완료 계정 설정이 원인이라는 근거가 없다.
화면의 최종 업데이트 9월 14일부터 점검일 9월 22일까지는 8일이다.
최종 업데이트가 실제 심사 시작일과 같다고 단정할 수는 없다.
Google은 일반적으로 며칠, 경우에 따라 2~4주가 걸린다고 안내한다.
사이트를 삭제하고 다시 등록하면 지연될 수 있다.
근거: [Google의 사이트 상태 설명](https://support.google.com/adsense/answer/12170222?hl=ko).

**코드 수정은 로컬 작업 폴더에 적용했으며 운영 배포·AdSense 계정 설정은 변경하지 않았다.**
Google의 심사 결과, 실제 크롤러 방문 기록, 계정 내 게시자 ID는 이 검사만으로 확인할 수 없다.
기술 오류 수정은 승인 보장이 아니다.

브라우저·Googlebot·Mediapartners-Google·AdsBot-Google 이름을 사용한 직접 요청에서도
ads.txt를 받을 수 있었다. 이 요청은 **우리 환경에서 보낸 요청**이며 Google의 실제 IP,
다른 지역의 Cloudflare 방화벽 동작이나 과거 크롤링 성공을 증명하지는 않는다.

따라서 `찾을 수 없음`의 원인이 현재 파일 누락·형식 오류라는 증거는 없다.
이 상태는 마지막 크롤링 결과이며 재수집 지연 또는 과거 접근 실패 가능성이 남는다.
Google은 ads.txt 변경 반영에 며칠, 광고 요청이 적으면 최대 한 달이 걸릴 수 있다고 설명한다.
정상 파일을 반복해서 바꾸거나 삭제하지 않는다.
근거: [ads.txt 가이드](https://support.google.com/adsense/answer/12171612?hl=ko),
[크롤링 문제 해결](https://support.google.com/adsense/answer/7679060?hl=ko).

| 푸터 안내 링크가 JavaScript에만 존재 | 소개·문의·개인정보·약관·가이드 링크를 정적 HTML에도 제공 |

| 오래된 JS와 새 JS가 섞일 수 있는 캐시 | 변경 스크립트·스타일·번역 사전에 버전 URL 적용 |
| 정치적 비유를 실제 지진 뉴스로 수집 | 명백한 비유 제목 4개 정리, 신규·기존 목록에 필터 적용. 실제 재난 보도는 보존 |
| 가스 누출 대응 순서·비상 식수 안내 | 우선 대피 및 안전한 장소에서 연락하도록 수정, 식수 기준 보완. 9개 언어에도 반영 |

referrer 이동이 실제 Google 제재를 받았다는 뜻은 아니다. 사용자와 크롤러가 다른 경로를
경험하는 불필요한 동작을 제거한 것이다.
근거: [Google 검색 스팸 정책](https://developers.google.com/search/docs/essentials/spam-policies#sneaky-redirects).
모바일 고정 광고도 기존 슬롯 ID가 비어 있어 실제 게재 중인 위반으로 단정하지 않았다.
근거: [고정 광고 구현 조건](https://support.google.com/adsense/answer/10734935?hl=en).

메타태그는 Google이 제공하는 소유권 확인 방식이다. 광고 로더를 제거한 것은 파일 발견
문제 자체의 해결책이 아니라, 심사 중 동의 및 광고 위치를 정리하기 위한 조치다.
승인 후 자동으로 광고가 켜지지는 않는다.
근거: [AdSense 연결 방법](https://support.google.com/adsense/answer/7584263?hl=en).

## 콘텐츠 검토

사이트에는 9개 실질적인 지진 가이드, 참고 자료, 데이터 출처, 소개·문의·개인정보·약관이
이미 있다. “글이 몇 개 미만이라 무조건 탈락”, “검색 색인이 없으면 무조건 탈락” 같은
임의 기준을 적용하지 않았다. 지도 및 직접 계산하는 통계는 방문자에게 실제 기능을 제공한다.
Google은 독창적이고 유용한 콘텐츠와 사용하기 쉬운 탐색을 요구한다.
근거: [심사를 위한 페이지 준비](https://support.google.com/adsense/answer/7299563?hl=ko).

뉴스·논문은 자동 수집 목록이라는 한계가 있다. 출처 링크가 있다는 사실만으로 독창적
콘텐츠 요건이 충족되는 것은 아니다. 광고를 재개할 때 이 목록들에 일괄 게재하지 말고
자체 해설의 실질적인 가치를 따로 평가해야 한다. 심사 대상은 사이트 전체이므로
광고 제거 또는 noindex만으로 콘텐츠 심사를 회피할 수 없다.
근거: [복제 콘텐츠 화면의 광고](https://support.google.com/publisherpolicies/answer/11190248?hl=ko).

안전 안내는 [적십자 지진 대응 지침](https://www.redcross.org/get-help/how-to-prepare-for-emergencies/types-of-emergencies/earthquake.html)과
[CDC 비상 식수 안내](https://www.cdc.gov/water-emergency/about/how-to-create-and-store-an-emergency-water-supply.html)를
참고했다. 비상 식수는 1인당 하루 최소 1 US gallon(약 3.8L), 최소 3일분으로 정정했다.

## 배포 후 확인 순서

1. 수정본을 Cloudflare Pages 운영 환경에 배포한다. 현재 저장소는 `main` push가 배포를
   유발하므로 이번 작업에서는 임의 push를 하지 않았다.
2. `python scripts/check_site.py --url https://worldearthquakelabs.com`으로 배포 결과를 검사한다.
3. AdSense → 사이트 → `worldearthquakelabs.com` → ads.txt **업데이트 확인**을 실행한다.
   소유권 확인 방식 선택이 다시 나타나면 메타태그를 사용할 수 있다.
4. 계정의 게시자 ID가 `pub-7720076982812531`과 같은지 대조한다. 코드와 파일끼리는
   일치하지만 첨부 화면에는 계정 ID가 보이지 않는다.
5. 이미 모든 단계를 완료한 심사 중 상태이므로 사이트를 삭제·재등록하지 말고 알림을 확인한다.
6. 계속 파일을 찾지 못하면 Cloudflare 보안 이벤트에서 실제 Google 크롤러 차단 여부를
   확인한다. 지금 검사에서는 차단이 재현되지 않았으므로 보안 규칙을 일괄 완화하지 않았다.
7. 승인 후 광고를 켜기 전에 AdSense의 개인정보 보호 및 메시지 설정을 점검한다.
   EEA·영국·스위스 개인 맞춤 광고에는 Google 인증 CMP가 필요하다. 실제 동의·거부·철회
   동작을 확인한 후 광고 코드와 정책 안내를 함께 업데이트한다.
   [Google CMP 요건](https://support.google.com/adsense/answer/13554116?hl=ko).

오류·경고 0개. Node 동작 회귀 2개와 Python 데이터·뉴스 회귀 4개 통과.
변경된 JavaScript 25개 파일과 Python 파일의 구문 검사 통과.
운영 사전 검사에서는 HTTP 요청 31건이 모두 200이었지만 기존 사이트맵 XML 오류와
광고 로더가 확인되었다. 운영 수정 완료를 뜻하지 않는다.

`scripts/check_site.py`는 HTML 구조, 내부 정적 링크, canonical·메타태그, 사이트맵,
ads.txt 형식·ID, robots 허용 여부, 광고 비활성 상태와 HTTP 응답을 검사한다.
동적 라우트는 별도로 집계한다. 링크된 외부 자료 전체의 정확성, 계정 CMP 설정,
Google 방화벽 로그, 실제 모바일 화면과 모든 상호작용까지 검사하는 도구는 아니다.

브라우저 연결 도구가 환경 오류로 실행되지 않아 실제 브라우저 시각 검증은 수행하지 못했다.
HTTP·정적 검사와 Node에서 실행한 데이터/리디렉션 회귀 검사로 검증했다.
수정된 새 영문 설명 중 일부는 기존 번역 사전의 정확한 문장 키와 달라 영어로 표시될 수 있다.
